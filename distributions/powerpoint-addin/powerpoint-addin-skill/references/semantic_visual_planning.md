# Semantic visual planning

For every created or materially recomposed substantive slide, define the
communication job, supported assertion, semantic relationship, primary visual
carrier, reading order, emphasis, audience density, argument importance,
layout fit, editability, accessibility, and fallback before choosing details.

## Bind decision-critical requirements

Extract every objective, numeric target, guardrail, decision condition, hard
constraint, and explicitly required evidence item before selecting layouts.
Give each a stable requirement ID, map it in DeckSpec to a target slide and
element, and define short verification tokens that must be visible in the
actual PowerPoint object.

Verify the final deck rather than planning records or notes. A historical
baseline does not cover a future target; an implication does not cover an
explicit guardrail. Missing or contradicted required items block delivery.
Prefer a concise KPI row or decision-condition strip over a low-value slide.

Use charts for quantitative relationships and tables for exact lookup. Use a
waterfall for explained change, timeline for dated sequence, process for ordered
actions, hierarchy for ownership, and matrix only when both axes matter. Use a
map only when location affects the conclusion and images only for context,
evidence, or human relevance. Keep required evidence editable.

Prefer one clear composition over repeated dashboard cards. Preserve
whitespace and parallel structure where useful. Map the plan to the 22 native
layouts after choosing the relationship and carrier. Populate placeholders
without moving them. Use Blank only when no standard layout works.

Heading layouts contain paired heading/body groups, not independent slots.
Before implementation, estimate capacity. Simplify, restructure, or split with
stable lineage rather than shrinking below a readable size.

Use direct language. Analytical slides may use supported findings as titles;
setup, process, and navigation slides may use plain topic titles. Voice,
density, and style findings are advisory unless they expose a concrete defect.
