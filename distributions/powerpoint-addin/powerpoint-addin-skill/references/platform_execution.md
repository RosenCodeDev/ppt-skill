# PowerPoint add-in execution

Work only in a saved working copy of the currently open PowerPoint
presentation. In Create mode, require the provided template or a
confirmed provisional fallback. Modify/Review uses the open deck as its design
authority.

Use PowerPoint-native layouts, placeholders, charts, tables, shapes,
connectors, notes, accessibility fields, and package checks exposed by the
add-in. Preserve masters, themes, fixed content, unknown parts, media,
embeddings, and unsupported objects outside authorized scope. Never assume a
local template, renderer, script, or icon archive exists.

Verify order/IDs, layouts, notes, macros, links, embedded data, protected
elements, placeholders, and unsupported objects. Render every final slide and
inspect it. Disclose checks that the add-in cannot perform.
